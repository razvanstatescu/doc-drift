Create a charge

Field

Type

Notes

amount

integer

Required. Minor units, 1 to 10,000,000 (100,000.00).

currency

string

Required. EUR, USD, GBP or RON.

source

string

Required. A tokenised card from checkout, starting with src_.

description

string

Optional. Shown to the merchant, not the cardholder.

Response

json

201 means we accepted the charge, not that the money moved. The charge goes pending, then settling, then settled. Listen for the charge.settled webhook, or poll GET /v2/charges/:id no more than once every 5 seconds.

Idempotency

Send a unique Idempotency-Key per logical charge and reuse it on every retry of that charge. Within 24 hours, a retry with the same key and body returns the original response with the header idempotent-replay: true. Background: .
