PAY-150 Refunds API v2

Last reviewed

2026-10-20

Overview

Use POST /v2/refunds for every new integration. It supports partial refunds and idempotency keys. POST /v1/refunds is deprecated and documented below only to help you migrate.

Create a refund (v2)

bash

Field

Type

Notes

charge_id

string

Required. The charge must be settled.

amount

integer

Required, in minor units. Several partial refunds are allowed while their sum stays at or below the charge amount.

reason

string

Optional: requested_by_customer (default), duplicate or fraudulent.

A successful call returns 201 with the refund in pending. It moves to succeeded when the PSP confirms, usually within 1 minute.

Errors

Status

Code

What to do

400

idempotency_key_required

Send an Idempotency-Key of at least 8 characters.

404

charge_not_refundable

The charge does not exist or is not settled yet. Retry after the charge.settled webhook.

409

idempotency_key_conflict

You reused a key with a different body. Use a new key.

422

amount_exceeds_refundable

The sum of refunds would pass the charge amount.
