Before you start

  • Node.js 24. The repo will not build on 22. With nvm: nvm install 24 && nvm use 24.

  • Docker, for a local Postgres.

  • Read access to nano-soft-dev/payments-api in Bitbucket. Ask in the team channel if you do not have it.

1. Clone and install

bash

2. Start Postgres

bash

Ask a teammate for the latest schema dump, or run the migrations from the payments-migrations repo.

3. Configure

Copy .env.example to .env. Every setting is read in src/config.ts; anything without a default must be set or the process exits at start-up with missing required env var. For local work these lines matter most:

bash.env

LOG_LEVEL=debug prints every request. Use info if it gets noisy. Never put a real PSP key in .env; the test key is enough for everything local.

4. Run it

bash

You should see ok. To run the settlement worker instead of the API, start it with PAYMENTS_ROLE=worker npm start.

5. Run the tests

bash

Tests use the built-in node:test runner and do not need the database.
