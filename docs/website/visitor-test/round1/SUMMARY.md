# Website v2, round 1: visitor test synthesis

2026-11-20. Four simulated first-time visitors, one agent each, read the new home page as screenshots, using [../questionnaire.md](../questionnaire.md). Answers are in `answers-*.md` here.

## Scores (1 to 5)

| --- | --- | --- | --- | --- | --- |
| Maya, Jira-first manager | 4 | 3 | 4 | 3 | 2 |
| Tomas, GitHub developer | 5 | 4 | 4 | 3 | 3 |
| Priya, Codegeist judge (about 8th of 40) | 5 | 4 | 4 | 3 | 3 |
| Daniel, Confluence platform lead | 4 | 4 | 4 | 3 | 3 |

## What worked

- **The first screen says what it does.** All four described the product correctly from the hero alone, quoting the lede.
- **The 3 a.m. terminal made the problem real** for Maya, Tomas and Daniel: "That is my life."
- **The real recording was the strongest proof.** Priya: "the single most credible thing on the page."
- **The agents switch landed** with Tomas and Daniel.
- **Trust lines** that landed: "Plain rules: same change, same result", "Agents never edit pages", and the honest FAQ limits.

## What all four hit (fixed in round 2)

1. **The hero stage is cut off at the fold**, and "flags it for AI agents" is unexplained above it.
2. **The stack only appears in the FAQ.** A GitHub user finds "Bitbucket only" at the very bottom.
3. **"The install link is shared with Codegeist 2026 judges first"** reads as a hackathon project. "Free today" raises the question of what comes later, and nothing says who makes it.
4. **It's too long and reads as a checklist:**
   - the pinned board has empty stretches;
   - the six tiles repeat how it works;
   - the four "Also" items were too many.
5. **Jargon:**
   - "Unanchored", "Pages anchored" and "anchors changed" appear in the visuals.
   - "Learns from dismissals" sounds like machine learning.
   - "High", "Told to AI agents" and "Forge" go unexplained.
6. **The agents section looked scripted** to the judge. It needs real Rovo and MCP output, labelled.
7. **Admins want a rollout path:** start with one space, set the sensitivity, see what it reads.

## Not a page bug

"Blank feature cards" and empty gaps in the full-page captures came from the capture method. Those screenshots were taken without scrolling, so the one-time reveals never fired. The scroll sheets show the visuals filled. Round 2 captures scroll through first.
