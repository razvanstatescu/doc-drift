In the full-page screenshots, several areas are blank (the six feature cards have empty tops, big white gaps around "AI agents"). I treat those as animation not captured and judged them from the scroll sheets, but a blank gap would make me think the page is broken.

## A. First screen only

1. It puts a "Possibly stale" label on a Confluence page when the code or Jira work behind it changes, so people and AI agents know not to trust it. ("When the code or Jira work behind a Confluence page changes, Doc Drift flags it for people and AI agents.")
2. "For teams with docs in Confluence". The card is a "Payments rollback runbook", so engineering and platform teams. I'm in Jira, so I'm not sure it's for me.
3. "See how it works". I rarely use Confluence, so "Install for Confluence" feels like a commitment. I want to understand it before I ask anyone for an install.
4. "Bitbucket" (I've never used it), "PR #482" (I can guess), "AI agents" flagged (which ones?), and the tooltip "PR #482 changed scripts/rollback.sh on Nov 13. Review." The headline "Docs that know when the code moved" is clear and a bit clever. The hero card is cut off at the bottom, so I can't see the whole picture.

## B. Whole page

5. The "It's 3 a.m." section. "The page's review date can't see a code change. And an AI assistant reads you the same old step." The terminal error "no such file or directory: ./scripts/rollback.sh" made the problem real. I half-understood it on the first screen and fully understood it here.
6. (1) Doc Drift links a Confluence page to the code files and Jira issues it mentions. (2) When one of those changes (a merged PR, a closed Jira issue), the page is marked "Possibly stale" within seconds and the owner is told. (3) A person checks it, often fixes it in one click, and it goes back to "Verified".
7. "Agents never edit pages. People do." Our Rovo agent and coding assistants "check Doc Drift before they rely on a page. If it may be out of date, they say so, and why." The Without/With toggle shows the same question answered with a warning. So no, an agent never edits a page. I did not fully get "coding assistants connect over MCP". I'd ask my devs.
8. For: "No AI decides what's stale", "Plain rules: same change, same result", "Page text changes only when a person clicks to fix it", "so page history can undo it", "Built on Atlassian Forge. No servers of ours in between", and the real-recording demo with a counter ("flagged 19 seconds later"). Against: I can't tell who made it. "The install link is shared with Codegeist 2026 judges first" reads like a hackathon project, not a supported product. There are no customers, logos or numbers on false alarms. "Doc Drift is free today" makes me wonder what happens later. I also don't know how noisy it is with 600 pages.

I also drifted in the Link/Change/Flag/Check pinned section because there is a lot of scrolling for four short lines. I stopped at the "Questions" FAQ and would not read it unless I was already interested. The "A person decides" section I skimmed because I'd already got the point.
